### 4.1 Convergence Profile: 'video'

| Parameter | Value | Description |
|-----------|-------|-------------|
| convergence_threshold | 0.005 | Shape change threshold (pixels) |
| rigid_iterations | 5 | Max iterations for RIGID phase |
| nonrigid_iterations | 5 | Max iterations for NONRIGID phase |
| min_iterations | 1 | Min iterations before convergence check |

### 4.2 Window Size Schedule

| Iteration | Window Size | Patch Scale |
|-----------|-------------|-------------|
| 0 | 11 | 0.25 |
| 1 | 9 | 0.35 |
| 2 | 7 | 0.50 |
| 3 | 5 | 1.00 |

### 4.3 Key Settings for C++ Matching

1. **Weights:** Uniform (1.0) for all 68 landmarks
   - C++ OpenFace uses weight=1.0, not patch_confidence values

2. **Convergence Check:** Max per-landmark displacement
   - `shape_change = np.max(np.linalg.norm(current - previous, axis=1))`
   - NOT total norm: `np.linalg.norm(current - previous)`

3. **Iteration Count:** 5 rigid + 5 nonrigid per window size
   - Matches C++ `num_optimisation_iteration = 5`

## 5. Test Methodology

### 5.1 Initialization
1. Load C++ initial parameters from `/tmp/cpp_iter0_start_params.txt`
2. Initialize Python params to EXACT same values as C++
3. Verify landmark positions match (should be < 0.0001 px error)

### 5.2 Per-Stage Optimization
For each window size (11, 9, 7, 5):
1. Get patch experts for the scale
2. Set uniform weights (1.0) for all landmarks
3. Run `optimizer.optimize()` with:
   - Same params from previous stage
   - Correct window_size and patch_scaling
   - sigma_components from CCNF model
4. Compare resulting landmarks to C++ reference

### 5.3 Error Computation
```python
errors = []
for idx in cpp_landmarks.keys():
    cpp_x, cpp_y = cpp_landmarks[idx]
    py_x, py_y = py_landmarks[idx]
    err = np.sqrt((py_x - cpp_x)**2 + (py_y - cpp_y)**2)
    errors.append(err)
mean_error = np.mean(errors)
max_error = np.max(errors)
```

## 8. Key Fixes Applied (Dec 2024)

### 8.1 Uniform Weights
**Before:** Used `patch_confidence` values (0.25-0.75) as weights
**After:** Use 1.0 for all landmarks
**Impact:** Hessian diagonal now matches C++ (tx=68, ty=68)

### 8.2 Convergence Check
**Before:** Total norm of all landmark changes
**After:** Max per-landmark displacement
**Impact:** Matches C++ convergence behavior

### 8.3 Iteration Count
**Before:** 10 rigid iterations (overshooting)
**After:** 5 rigid iterations (matching C++)
**Impact:** WS11 error improved from 0.015px to 0.00017px (91x better)
